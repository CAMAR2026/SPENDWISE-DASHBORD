# SpendWise Dashboard

SpendWise is a responsive personal finance dashboard shell built using HTML and CSS.

## Features

- Responsive dashboard layout
- Sidebar navigation
- Dashboard header
- Six spending category cards
- CSS Grid for the overall layout
- Flexbox for internal components
- CSS custom properties for consistent colors
- Hover and keyboard focus animations
- Responsive design for screens below 768px
- Dark theme support using `prefers-color-scheme`

## Dashboard Categories

The dashboard includes:

- Food
- Transport
- Rent
- Entertainment
- Savings
- Utilities

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Custom Properties
- Responsive Media Queries
